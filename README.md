# Телеграм-бот для бронирования отелей в России

Привет! Это простенький телеграм бот, который ищет отели в российских городах, показывает цены и даже может записать бронь. Понимает запросы типа «Москва с 10.08 по 15.08, бюджет 5000, 2 человека» или просто город — дальше спросит сам.

## Что умеет

- Вытаскивать город, даты, бюджет и гостей из обычного сообщения (ну, пытается)
- Показывать календарь для выбора дат заезда/выезда
- Реальные цены через LiteAPI (пока тестовый ключ, но работает)
- Сортировать отели по цене + рейтингу + прошлым броням пользователя
- Сохранять бронирования в sqlite базе
- Более умные рекомендации если вы уже бронировали раньше

## Что нужно для запуска

- Питон 3.8+ (должно работать и на новее)
- Токен бота от @BotFather
- Ключ от LiteAPI (для теста можно сэндбокс как в коде)

Поставьте зависимости:
